# Android スマートフォン用 姿勢・顔検出デモアプリ

スマートフォンのカメラを使ってリアルタイムで体の姿勢または顔を検出し、ワイヤーフレームを表示するデモアプリです。

## 特徴

- 📱 **スマートフォン対応**: Android/iOSのブラウザで動作
- 🎥 **リアルタイム処理**: 端末上で高速に動作
- 🎯 **姿勢検出**: TensorFlow.js MoveNetを使用して体の17個のキーポイントを検出
- 👤 **顔検出**: MediaPipe FaceDetectorを使用して顔とキーポイントを検出
- 🔄 **モデル切替**: 体検出と顔検出をリアルタイムで切り替え可能
- 🖼️ **ワイヤーフレーム表示**: 検出した姿勢や顔をリアルタイムで可視化
- 📷 **カメラ切替**: フロント/バックカメラの切り替えが可能
- ⚡ **軽量**: HTML1ファイルで完結するシンプルな構成
- 💾 **モデルキャッシュ**: Service Workerを使用してモデルファイルを自動キャッシュ、2回目以降は高速起動

## 使い方

### 1. ファイルの配置

`index.html` をWebサーバーに配置するか、ローカルで開きます。

### 2. スマートフォンでアクセス

#### 方法A: 簡単な方法（Pythonを使用）
```bash
# プロジェクトフォルダで以下のコマンドを実行
python3 -m http.server 8000
```

その後、スマートフォンのブラウザから以下にアクセス：
- 同じWi-Fiネットワーク上のPCのIPアドレス:8000
- 例: `http://192.168.1.100:8000`

#### 方法B: GitHub Pagesを使用
1. このリポジトリをGitHubにプッシュ
2. Settings → Pages → Sourceで "main" ブランチを選択
3. 生成されたURLにスマートフォンでアクセス

### 3. アプリの使用

1. ブラウザで `index.html` を開く
2. 「カメラを起動」ボタンをタップ
3. カメラへのアクセスを許可
4. 画面に体が映ると自動的に姿勢が検出され、ワイヤーフレームが表示されます
5. 「体検出 ⇄ 顔検出」ボタンで検出モードを切り替え可能
6. 「カメラ切替」ボタンでフロント/バックカメラを切り替え可能

## 技術仕様

### 使用技術
- **TensorFlow.js 4.11.0**: 機械学習ライブラリ
- **Pose Detection 2.1.0**: 姿勢検出モデル
- **Face Detection 1.0.1**: 顔検出モデル
- **MoveNet Lightning**: 軽量・高速な姿勢検出モデル
- **MediaPipe FaceDetector**: 高精度な顔検出モデル

### 体検出: 検出されるキーポイント（17箇所）
- 鼻、左目、右目、左耳、右耳
- 左肩、右肩、左肘、右肘、左手首、右手首
- 左腰、右腰、左膝、右膝、左足首、右足首

### 顔検出: 検出される要素
- 顔のバウンディングボックス
- 顔のキーポイント（目、鼻、口など）

### ブラウザ要件
- カメラアクセスをサポートするモダンブラウザ
  - Chrome for Android
  - Safari (iOS 14+)
  - Firefox for Android
- **注意**: HTTPSまたはlocalhostからのアクセスが必要（カメラアクセスのため）

## パフォーマンス

- **FPS**: 通常15-30 FPS（端末の性能による）
- **レイテンシ**: 低遅延（端末上で処理）
- **モデル**: MoveNet Lightning（最軽量版）を使用
- **起動時間**: 
  - 初回: 10-30秒（モデルのダウンロード + 初期化）
  - 2回目以降: 3-5秒（キャッシュから読み込み）

## モデルキャッシュ機能

このアプリは **Service Worker** を使用して、TensorFlow.js のモデルファイルを自動的にブラウザにキャッシュします。

### 仕組み

1. **初回アクセス時**: モデルファイル（.bin, .json）をCDNからダウンロードし、ブラウザのキャッシュに保存
2. **2回目以降**: キャッシュされたモデルファイルを使用するため、ダウンロード時間が不要になり高速起動
3. **キャッシュステータス表示**: 画面左上に「📦 初回ダウンロード」または「💾 キャッシュ済み (Xファイル)」と表示

### メリット

- ⚡ **高速起動**: 2回目以降はモデルのダウンロードが不要
- 📶 **オフライン対応**: 一度ダウンロードすれば、オフラインでも使用可能（カメラのみ必要）
- 💰 **データ通信量の削減**: モデルファイルを毎回ダウンロードしないため、通信量を節約

### キャッシュのクリア（開発者向け）

ブラウザのコンソールで以下のコマンドを実行すると、キャッシュをクリアできます：

```javascript
clearModelCache()
```

または、ブラウザの設定から「キャッシュされた画像とファイル」を削除してください。

## ブラウザキャッシュ対策

このアプリには、HTMLを更新した際にブラウザキャッシュの影響を受けないよう、以下の対策が実装されています：

### 1. キャッシュコントロールメタタグ
HTMLファイルに以下のメタタグが追加されており、HTMLファイル自体がキャッシュされません：
```html
<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">
<meta http-equiv="Pragma" content="no-cache">
<meta http-equiv="Expires" content="0">
```

### 2. バージョン管理
画面左下にバージョン番号と更新日が表示されます。これにより、最新版が表示されているか確認できます。

### 3. 更新時の手順（開発者向け）
アプリを更新する際は、以下のバージョン情報を更新してください：
```javascript
const APP_VERSION = '1.0.0';  // バージョン番号を更新
const BUILD_DATE = '2025-11-11';  // 更新日を変更
```

### 4. ユーザー側でのキャッシュクリア方法
それでも更新が反映されない場合は、以下の方法を試してください：

#### スマートフォン（Chrome/Android）
1. ブラウザのメニュー → 「設定」
2. 「プライバシーとセキュリティ」
3. 「閲覧履歴データの削除」
4. 「キャッシュされた画像とファイル」を選択して削除

#### スマートフォン（Safari/iOS）
1. 「設定」アプリ → 「Safari」
2. 「履歴とWebサイトデータを消去」

#### 強制リロード（簡単な方法）
- アドレスバーを長押し → リロード
- または、ブラウザのタブを完全に閉じて再度開く

## トラブルシューティング

### HTMLを更新しても反映されない
1. 画面左下のバージョン番号を確認（例：v1.1.0 (2025-11-11)）
2. 期待しているバージョンと異なる場合は、上記「ユーザー側でのキャッシュクリア方法」を実行
3. プライベートブラウジング（シークレットモード）で開いて確認
4. 別のブラウザで試す

### モデルが毎回ダウンロードされる
1. 画面左上に「💾 キャッシュ済み」と表示されているか確認
2. Service Worker が正しく動作しているか確認（ブラウザのコンソールでエラーを確認）
3. HTTPSまたはlocalhostからアクセスしているか確認（Service WorkerはHTTPSが必要）

### カメラが起動しない
- ブラウザのカメラ権限を確認してください
- HTTPSまたはlocalhostからアクセスしているか確認してください
- 他のアプリがカメラを使用していないか確認してください

### 動作が遅い
- ブラウザを再起動してみてください
- 他のタブやアプリを閉じてください
- 端末のパフォーマンスモードを有効にしてください

### 姿勢が正しく検出されない
- 明るい場所で使用してください
- カメラから1-3メートルの距離で全身が映るようにしてください
- 体全体がフレームに収まるようにしてください

```javascript
const minConfidence = 0.3; // 0.0-1.0の範囲で調整
```

### ワイヤーフレームの色変更
```javascript
ctx.strokeStyle = '#00ff00'; // お好みの色に変更
ctx.fillStyle = '#00ff00';
```

```javascript
detector = await poseDetection.createDetector(
    poseDetection.SupportedModels.MoveNet,

        modelType: poseDetection.movenet.modelType.SINGLEPOSE_THUNDER // より高精度

```
